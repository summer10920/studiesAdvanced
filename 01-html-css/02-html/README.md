# HTML 練習

對應講義 [HTML 基本教學：文件結構與常用標籤](https://summer10920.github.io)（`lokiTech-15day-02-html`）。每一資料夾是該節的起點，不是完成版。請依 `index.html` 裡的 TODO 自己補標記。

| 資料夾 | 講義小節 |
| --- | --- |
| `01-shell/` | 檔案一覽 |
| `02-box/` | 區塊與行內 |
| `03-layout/` | 語意標籤 |
| `04-headings/` | 標題與段落 |
| `05-links/` | 連結 |
| `06-text/` | 文字效果與實體 |
| `07-lists/` | 清單 |
| `08-media/` | 多媒體 |
| `09-table/` | 表格 |
| `10-form/` | 表單 |
| `11-a11y/` | 選讀：無障礙（a11y） |

用 VS Code 的 Live Server 開啟該資料夾的 `index.html`。改完存檔後重新整理。圖片用 [picsum.photos](https://picsum.photos/) 與 [placehold.co](https://placehold.co/)，不要把圖檔放進倉庫。
