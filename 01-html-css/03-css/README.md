# CSS 練習

對應講義 [CSS 基礎：選擇器、盒模型、Flex、Grid、RWD](https://summer10920.github.io)（`lokiTech-15day-03-css`）。樣式寫在各資料夾的 `style.css`，`index.html` 只留結構。選讀資料夾可以先跳過。

| 資料夾 | 講義小節 |
| --- | --- |
| `01-syntax/` | 規則的零件 |
| `02-where/` | 三種寫法 |
| `03-selectors-basic/` | 元素、class 與 id |
| `04-selectors-combine/` | 組合關係 |
| `05-selectors-pseudo/` | 偽類與偽元素 |
| `06-specificity/` | 四欄權重 |
| `07-inherit/` | 什麼會繼承 |
| `08-keywords/` | 四個關鍵字 |
| `09-units/` | 長度 |
| `10-colors/` | 顏色寫法 |
| `11-type/` | 字型堆疊 |
| `12-text/` | 行內文字 |
| `13-background/` | 背景圖層 |
| `14-selectors-extra/` | 屬性比對與 :is()、:where()、:has() |
| `15-layer/` | 自訂屬性與 @layer |
| `16-box/` | 盒子模型 |
| `17-display/` | display |
| `18-position/` | 定位與 z-index |
| `19-overflow/` | overflow |
| `20-flex/` | Flexbox |
| `21-grid/` | Grid |
| `22-rwd/` | 列印與偏好 |
| `23-vars/` | 宣告、繼承與備援 |
| `24-motion/` | 動畫自己播放 |
| `25-inspect/` | 動畫面板 |
| `26-float/` | 不要拿來做多欄 |
| `27-flip/` | 視距與背面 |
| `28-read-extra/` | 語法與初始值 |

用 VS Code 的 Live Server 開啟該資料夾的 `index.html`。改完存檔後重新整理。圖片用 [picsum.photos](https://picsum.photos/) 與 [placehold.co](https://placehold.co/)，不要把圖檔放進倉庫。
