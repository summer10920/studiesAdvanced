# JavaScript 練習

對應講義「JavaScript 基礎：值、函式、陣列與模組」（`lokiTech-15day-06-js-basics`）、「JavaScript：BOM、DOM 與事件」（`lokiTech-15day-07-js-dom`）與「JavaScript：非同步、Fetch 與瀏覽器儲存」（`lokiTech-15day-08-js-async`）。`pages/` 裡每一頁就是講義裡對應 demo 的完整檔案，複製貼上就能執行。

用 VS Code 開啟 `01-html-css-js/`，對 `04-js/index.html` 用 Live Server 開啟，寬螢幕左邊是選單，窄螢幕改成上方選單。有用到 `fetch` 或模組的頁面一定要用 Live Server，直接雙擊檔案會讀不到。

幾個由多個檔案組成的 demo：`03b-js-console`、`88-js-defer`、`90-js-module` 各自載入同名的 js；`82-js-module` 與 `83-js-default` 是匯入與匯出示範。讀取用的 JSON 放在 `pages/data/`。完成版以 `.final` 結尾，目前有 `147`、`148`、`181`、`186` 四個。
