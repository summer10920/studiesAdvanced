對應講義「JavaScript 基礎：值、函式、陣列與模組」（`lokiTech-15day-06-js-basics`）。`pages/` 裡每一頁是該節的起點，完成的寫法在講義裡。多數頁面只負責載入同名的 `.js`，結果看 DevTools 的 Console。`pages/01-js-inline.html` 的程式寫在 HTML 裡，沒有另開 js。選讀頁可以先跳過。
