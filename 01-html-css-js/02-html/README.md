# HTML 練習

對應講義 [HTML 基本教學：文件結構與常用標籤](https://summer10920.github.io)（`lokiTech-15day-02-html`）。`pages/` 裡每一頁是該節的起點，不是完成版。請依該頁的 TODO 自己補標記。

用 VS Code **檔案 → 開啟資料夾** 打開 `01-html-css-js/`。在檔案總管對 `02-html/index.html` 右鍵 **Open with Live Server**。左邊選單換右邊 iframe 的頁面；第一頁是「檔案一覽」。改完存檔後重新整理。圖片用 [picsum.photos](https://picsum.photos/) 與 [placehold.co](https://placehold.co/)，不要把圖檔放進倉庫。
