# React Router

對應講義 React Router（`lokiTech-15day-11-react-router`）。

`04-react-router` 是路由 API 的練習專案。`travel` 是把洛奇旅行從狀態切頁改成多頁的另一個 Vite 專案。兩邊都從 `react-router` 引入，React 19。宣告式路由，不用 data router 的 loader 與 action。

```bash
pnpm install
pnpm build
```

`travel` 要在那個資料夾另外安裝再建置。入口是起始版。檔名以 `.final` 結尾的是講義走完的完成內容，不會被起始入口引入。
